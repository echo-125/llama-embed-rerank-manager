# 常见问题

| 问题 | 说明 |
|---|---|
| 换 embedding 模型要重建索引 | 不同维度或不同模型的向量不可混用；以模型文件页显示的维度为准 |
| 重排分数不是概率 | bge 输出原始 logit；需要概率时做 sigmoid |
| 上下文截断 | 两个模型上下文均为 4096 token，超长文本先切块 |
| 无鉴权 | 只监听本机；若改 `0.0.0.0` 必须加 `--api-key` |
| 显存不足 | 两个模型合计约 6 GB；可把启动参数中的 `-c 4096` 调小（见 `src/service.rs` 的 `extra_args`） |
| 模型下拉为空 | 只显示同类型模型；确认文件名包含对应关键字（见 [模型管理](models.md)） |
| 维度显示 `—` / `未知` | GGUF 元数据中没有可识别的 `<arch>.embedding_length`，或文件不是向量模型 |
| 接入模型名是什么 | 所选 GGUF 文件名去掉 `.gguf`；API 弹窗会显示当前名称 |
| 移除导入会删文件吗 | 不会。模型只是从列表隐藏，文件仍在原目录；点击「恢复已移除」可重新显示 |
| 模型起不来 | 查看 GUI 的「运行日志」Tab；确认 Llama 桌面端已安装、模型文件存在 |
| 端口被占用 | `netstat -ano \| findstr 9932`；先停止再启动；两个端口不能相同 |
| 退出后模型会停吗 | 「设置」中可控制退出时是否停止模型；关闭按钮默认最小化到托盘 |
| 首次加载慢 | 4B 模型加载约 20~30 秒，属正常 |
