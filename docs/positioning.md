# 产品定位

## 一句话

把本机的**向量化（embedding）**与**检索重排（rerank）**模型稳定地跑起来，并提供轻量的桌面管理界面。

## 目标用户

- 在本地运行 RAG / Agent 应用，需要一个稳定的本机检索底座
- 不想引入 Python、Node、Docker 或整套模型平台
- 希望模型按需启动、随时停止，空闲时不占资源

## 与同类工具的差异

本地模型工具大多走"全家桶"路线：内置聊天界面、模型市场、自动下载、多引擎适配，代价是常驻进程多、内存占用高、启动慢。llama.cpp 官方 Windows 桌面端则只覆盖对话模型，向量化、重排仍需自己敲命令行。

本项目坚持以下原则：

- **轻量**：单个 Rust 可执行文件，无 Python / Node / 容器运行时；`llama.exe` 复用 Llama 桌面端
- **低占用**：两个模型按需启动、用完可停；GUI 只负责进程、端口、健康检查和日志
- **快启动**：一个模型对应一个 llama-server 进程，参数固定、无编排层
- **范围明确**：只管理 embedding 与 rerank

## 明确不做

- 模型训练 / 转换 / 量化
- 内置聊天客户端
- 对话、VLM、翻译等生成式模型
- 模型市场 / 自动下载
- OCR、ASR/TTS、图像生成等需要额外推理运行时的能力
- 多模型编排 / 工作流引擎

功能取舍有疑问时，优先选择"少一个依赖、少一个常驻进程"的方案。
